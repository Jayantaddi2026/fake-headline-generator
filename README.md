
# Fake Headline Generator

A Python-based command-line application that generates humorous and fictional news headlines using randomly selected subjects, actions, and locations.

## Features

- Random headline generation
- Interactive command-line interface
- Multiple headline combinations
- Continuous headline generation
- Simple and lightweight application
- No external dependencies

## Technologies Used

- Python 3
- Python Random Module
- Visual Studio Code

## Python Concepts Used

- Lists
- Random Module
- While Loop
- Conditional Statements
- F-Strings
- User Input
- String Manipulation

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run the following command:

   python fake_headline_generator.py

## Sample Output

    BREAKING NEWS: A Mumbai Cat celebrates at India Gate

    Do you want another headline? (yes/no): no

    Thanks for using the headline generator. Have a fun day!

## Disclaimer

All generated headlines are fictional and intended
for educational and entertainment purposes only.
They do not represent real news or events.
